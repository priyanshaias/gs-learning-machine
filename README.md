# GS Learning Machine

A personal reader: highlight books in four colours, keep notes, and save each set of highlights and notes as a *knowte*.

This repository holds only the app. Books and knowtes live in a separate private repository and are read and written through the GitHub API with a fine-grained token that is stored only in the browser.

- `index.html`: the whole app (fonts embedded)
- `sw.js`, `manifest.json`, icons: lets it install to the home screen and open offline
